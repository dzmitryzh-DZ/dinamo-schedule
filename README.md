# ХК Динамо-Минск — Расписание

Веб-версия расписания дня и тренировочных групп: вкладки «День» и «Месяц»,
копирование расписания в WhatsApp, сохранение на Яндекс.Диск, вход по паролю.

## Вход

Пароль по умолчанию: `dinamo2026`. Сменить: ⚙ Настройки → Смена пароля
(новый пароль действует в этом браузере). Чтобы зашить другой пароль в код,
подставьте его SHA-256 (hex) в `src/config.ts`.

## Синхронизация с Яндекс.Диском

1. Получите OAuth-токен: https://yandex.ru/dev/disk/poligon → «Получить OAuth-токен».
2. В приложении: ⚙ Настройки → вставьте токен → «Сохранить токен».

Расписание сохраняется в файл `app:/schedule.json` (папка приложения на Диске)
и подтягивается на любом устройстве с тем же токеном. Без токена данные
хранятся только в браузере.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
```

Деплой на GitHub Pages: сборка публикуется из ветки `gh-pages`.
